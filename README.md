# ascii-art-game

An ASCII management and dungeon delving game inspired by **A Dark Room**, with light Dungeons & Dragons flavoring.
You begin in a cold room with a dying fire, build a village, recruit adventurers, and push deeper into a haunted dungeon.

## Run
Open `./index.html` in a browser.

## Controls
- Click an action button or press its shown key (1-0, then Q/W/E/R/T).
- Actions unlock as you gather resources, build structures, and open the dungeon.

## Gameplay Loop
- **Room:** gather wood, stoke the fire, and build the first hut.
- **Village:** manage wood/food/hide/iron/relics, grow the settlement, and train adventurers.
- **Dungeon:** roll dice on each delve, take risks, and return with relics and iron.
